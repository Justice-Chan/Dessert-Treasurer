# Security policy

## Supported version

Security fixes are provided for the latest released version of Dessert Treasurer.

## Reporting a vulnerability

Please do not open a public GitHub issue for a vulnerability, private data exposure, or a possible loss of accounting records.

Use an established private contact channel with the maintainer and include:

- A concise description of the issue.
- Steps to reproduce it with non-sensitive sample data.
- The app version, operating system and operating-system version.
- The potential effect on local data, backups, or attachments.

GitHub private vulnerability reporting is not currently enabled. Do not use public issues or discussions to send sensitive details. No fixed response-time commitment is provided.
