# 總務交接指南

給下一任總務。不需要會寫程式，照著做即可。

## 這套系統有哪些東西

| 東西 | 用途 | 在哪裡 |
| --- | --- | --- |
| 報帳網站 | 幹部送報帳；總務審核、付款、記帳 | <https://justice-chan.github.io/Dessert-Treasurer/> |
| 記帳 app | 記帳、付款、對帳、月報、人員與活動 | 總務的電腦 |
| 試算表「Access Sheet」 | 權限表、報帳申請、操作紀錄 | 管理者的 Google 雲端硬碟 |
| 收據資料夾 | 每月一個資料夾（例如 `2026-11`），底下依活動分類；雲端帳本「甜點社帳本.json」也在這裡 | 同上 |

收支、報銷、帳戶和對帳存在雲端帳本，網站和 app 共用；人員和活動只存在 app 的電腦裡。

## 交接當天要做的事

1. **更新權限表**（試算表的「權限表」分頁），每人一列：

   | email | 職位 | 姓名 | 備註 |
   | --- | --- | --- | --- |
   | 登入用的 Google 帳號 | 填「總務」才能審核，其他職位都算幹部 | 顯示在網站左下角 | 給人看的筆記，系統不讀 |

   卸任的人整列刪掉；他們的舊申請會歸在「已離任」。
2. **讓新總務能用記帳 app**：舊總務在 app「備份」頁的「匯出」匯出完整備份交給新總務，新總務在自己的電腦用「還原」匯入，人員和活動才會帶過去。收支和報銷在雲端，同步後就會出現。
3. **換同步金鑰**：請管理者在 Apps Script 的 Script Properties 把 `SYNC_SECRET` 改成新值（至少 32 個字元），新總務在 app「設定 → 雲端帳本同步」填入。舊金鑰會立刻失效。
4. **確認收據資料夾**：新總務的帳號要能開啟收據資料夾。

## 平常的流程

1. 幹部在網站「新增報帳」：選活動、填金額、拍收據。送出後可以在「我的申請」修改所有內容，包括活動和收據；只有已付款的申請不能改金額。已核准或退回的申請改完會回到待審核，要重新審核。
2. 總務在網站「審核報帳」：點開申請，用「改為」選單核准、退回或撤銷。退回要寫原因。總務自己的申請也在這裡，標「本人」，點開後可以按「修改」。
3. 付款後，在同一頁改為「已付款」，填付款日期和帳戶，按「記錄付款」，帳本就會扣款。也可以在記帳 app「報銷」對已核准的申請按「付款」。
4. 其他收入支出在網站「記帳」或 app 的「記帳」新增，兩邊看到的是同一本帳。

## 每個月

- 網站總覽的餘額和支出直接由雲端帳本算出，不用等 app 同步。
- 在 app「對帳」頁核對現金和銀行餘額並鎖定月份；鎖定的月份在網站和 app 都不能改。
- 關閉記帳 app 時，若帳務有變動，會自動把完整備份存到雲端硬碟的「甜點社總務備份」資料夾（檔名是「甜點社帳務自動備份_月-日」，只保留最新一份），在 app「備份」頁可以看到上次備份的時間和位置，按「變更」可以換資料夾。
- 試算表和雲端帳本每月 1 日會自動備份到雲端帳本所在資料夾底下的「備份」，各保留最近 12 份，不用手動處理。帳本備份可以在 app「備份」頁的「還原」匯入；還原前 app 會先把目前資料另存為「甜點社還原前備份_日期.json」。
- 每月 1 日中午會把上個月的月結報表存成 PDF（「甜點社N月月結報表.pdf」），放在雲端帳本所在的資料夾，格式和 app 列印的一樣。對帳要在這之前完成，報表才會寫「月結已核對」。

## 不要這樣做

- 不要直接刪「報帳申請」的列：收據會留在雲端硬碟，已付款的那筆 app 也不會移除。要刪請在網站撤銷。
- 不要調整試算表的欄位順序或第一列標題，也不要改 id 欄；刪除整列沒關係。
- 不要改月份資料夾的名稱格式（`YYYY-MM`），網站靠這個找活動。
- 不要把同步金鑰傳到群組或寫在公開的地方。

## 出問題時

| 狀況 | 怎麼辦 |
| --- | --- |
| 有人登入看到「無權限」 | 確認權限表 A 欄是他登入用的帳號、B 欄有填職位 |
| 「登入已過期」 | 重新登入即可 |
| 新增報帳讀不到活動 | 選「其他（新活動）」直接輸入，系統會自動建資料夾 |
| app 同步失敗 | 確認 app 設定裡的網址和金鑰，與 Script Properties 的 `SYNC_SECRET` 一致；沒上傳的變更會留在電腦裡，下次同步再傳 |
| app 說「有 N 筆紀錄網頁也改過」 | 網站和 app 改到同一筆紀錄，那幾筆以網站為準，其他變更都已上傳；需要的話在 app 重改那幾筆 |
| app 說「網頁上的帳本比較新」 | 上次關閉 app 時有變更沒上傳，期間網站又改了帳；app 那批變更沒有上傳，已改用雲端的帳本，確認後重新輸入 |
| 網站記帳頁說「雲端帳本還沒建立」 | 打開記帳 app 同步一次，app 會把現有的帳上傳 |
| 其他系統錯誤 | 請管理者在 Apps Script 執行 `checkSetup`，看哪一項打叉 |
